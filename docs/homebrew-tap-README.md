# homebrew-cc-doctor

Homebrew tap for installing [CC Doctor](https://github.com/diaojz/cc-doctor) on macOS.

## Install

```bash
brew tap diaojz/cc-doctor
brew install --cask cc-doctor
```

## Upgrade

```bash
brew upgrade --cask cc-doctor
```

## Uninstall

```bash
brew uninstall --cask cc-doctor
```
